## Что делает мод

Одна команда в чате превращает то, что вы сейчас видите в игре, в классический демотиватор: снимок на чёрном фоне в тонкой белой рамке, под ним крупный заголовок с засечками и мелкая подпись.

- Перед снимком мод закрывает чат и на мгновение прячет интерфейс (HUD), поэтому на картинке только мир.
- Собирает картинку и пишет файл в фоновом потоке: игра не подвисает даже на больших разрешениях.
- Сохраняет PNG в папку скриншотов и сразу показывает превью.
- Шрифты, размеры, отступы и цвета настраиваются.

Мод работает только у вас на компьютере. На сервер ставить его не нужно, и сервер ничего не узнаёт о снимке: команда `/demotivate` обрабатывается на клиенте и в чат не отправляется.

## Установка

1. Установите [Fabric Loader](https://fabricmc.net/use/installer/) `0.19.3` или новее для Minecraft 26.3.
2. Положите в папку `mods` [Fabric API](https://modrinth.com/mod/fabric-api) для 26.3.
3. Положите в `mods` файл `demotivator-1.1.0.jar` (как собрать — в разделе [Сборка из исходников](#сборка-из-исходников)).
4. Необязательно: [Mod Menu](https://modrinth.com/mod/modmenu), чтобы открывать настройки из списка модов.

Нужна Java 25.

## Первый демотиватор

1. Встаньте так, чтобы в кадре было то, что нужно.
2. Откройте чат и введите:

   ```
   /demotivate Копал прямо вниз | и нашёл лаву. Опыт бесценен.
   ```

3. Чат закроется, через 3 тика сделается снимок без интерфейса.
4. Откроется превью, а в чат придёт сообщение со ссылкой на файл и на папку.

## Команды

| Команда | Что делает |
|---|---|
| `/demotivate <заголовок>` | снимок с одним заголовком |
| `/demotivate <заголовок> \| <подпись>` | заголовок и мелкая подпись под ним |
| `/demotivator` | открыть настройки |
| `/demotivator config` | то же самое |
| `/demotivator last` | показать последний сделанный демотиватор |
| `/demotivator folder` | открыть папку с картинками |
| `/demotivator help` | краткая справка в чате |

Клавиши «Открыть настройки Demotivator» и «Показать последний демотиватор» есть в **Настройки → Управление → Demotivator**. По умолчанию они не назначены, чтобы не мешать другим модам.

## Как писать текст

- Всё до первого `|` — заголовок, всё после — подпись.
- Если `|` нет, подпись берётся из настройки «Подпись по умолчанию» (по умолчанию пустая).
- `\n` внутри текста — ручной перенос строки, например `/demotivate Первая строка\nВторая строка`.
- Длинный текст переносится по словам сам.
- Пустая команда (`/demotivate` без текста) ничего не снимает и подсказывает, как написать текст.

## Экран превью

После снимка открывается экран с картинкой, её именем и размером в пикселях. Кнопки:

- **Открыть картинку** — открывает PNG в программе по умолчанию;
- **Открыть папку** — открывает папку с демотиваторами;
- **Настройки** — экран настроек мода;
- **Закрыть** или `Esc`.

Если превью выключено в настройках, картинка всё равно сохраняется, а ссылка приходит в чат. Последний демотиватор можно открыть снова командой `/demotivator last`.

## Настройки

Экран настроек открывается командой `/demotivator`, клавишей или через Mod Menu. Неверное значение подсвечивается красным, и кнопка «Сохранить» не нажимается, пока его не исправить. «Сбросить» возвращает значения по умолчанию, «Отмена» закрывает экран без сохранения.

### Вкладка «Быстрый доступ»

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Скрывать HUD | вкл. | прятать интерфейс на время снимка |
| Показывать превью | вкл. | открывать экран превью после снимка |
| Сообщение в чат | вкл. | писать в чат ссылку на файл и папку |
| Задержка снимка (тики) | 3 | сколько тиков ждать после закрытия чата, от 1 до 60. Увеличьте, если на снимок попадает чат или интерфейс |
| Папка внутри screenshots/ | `demotivators` | куда класть картинки. Разрешены буквы, цифры, пробелы, точки, дефисы и подчёркивания |
| Подпись по умолчанию | пусто | подпись, если в команде нет `\|`, до 128 символов |

### Вкладка «Стиль постера»

| Настройка | По умолчанию | Допустимо | Что делает |
|---|---|---|---|
| Ширина картинки (пикс.) | 1000 | 320–3840 | ширина готового PNG; высота подбирается по снимку и тексту |
| Внешний отступ (%) | 10 | 2–30 | поле вокруг снимка, в процентах от ширины |
| Толщина рамки (пикс.) | 3 | 0–40 | толщина белой рамки; 0 — без рамки |
| Зазор рамки (пикс.) | 4 | 0–40 | расстояние между снимком и рамкой |
| Размер заголовка (%) | 8 | 2–20 | высота букв заголовка в процентах от ширины |
| Размер подписи (%) | 3.6 | 1–12 | высота букв подписи |
| Заголовок капсом | выкл. | | писать заголовок заглавными буквами |
| Шрифт заголовка | Times New Roman | любой шрифт системы | если шрифта нет, берётся стандартный шрифт с засечками |
| Шрифт подписи | Arial | любой шрифт системы | если шрифта нет, берётся стандартный шрифт без засечек |
| Цвет фона | `#000000` | `#RRGGBB` | рядом с полем показан образец цвета |
| Цвет рамки | `#FFFFFF` | `#RRGGBB` | |
| Цвет заголовка | `#FFFFFF` | `#RRGGBB` | |
| Цвет подписи | `#FFFFFF` | `#RRGGBB` | |

Если шрифт с таким именем не установлен, под полем появляется предупреждение, но сохранить настройки можно.

## Файлы

- `screenshots/demotivators/demotivator_ГГГГ-ММ-ДД_ЧЧ.ММ.СС.png` — готовые картинки. Если за секунду сделано несколько, к имени добавляется номер.
- `config/demotivator.json` — настройки. Записываются атомарно, рядом лежит резервная копия `demotivator.json.bak`, из которой мод читает настройки, если основной файл повреждён.

## Частые вопросы

**На снимке остался чат или интерфейс.** Увеличьте «Задержку снимка» до 5–10 тиков. Это бывает с модами, которые рисуют свой интерфейс с задержкой.

**Появилось «Снимок отменён: открыт другой экран».** Мод ждёт до 10 секунд, пока закроется открытый экран (например, инвентарь). Закройте его и повторите команду.

**Появилось «Демотиватор создавался слишком долго и был отменён».** На сборку картинки отводится 30 секунд. Обычно это значит, что выбрана очень большая ширина на слабом компьютере. Уменьшите «Ширину картинки».

**Появилось «Демотиватор уже создаётся».** Предыдущая команда ещё не закончила работу. Подождите секунду.

**Русские буквы не отображаются.** Выбран шрифт без кириллицы. Укажите шрифт с кириллицей, например Times New Roman, Arial, Georgia или Segoe UI.

**Видят ли другие игроки команду?** Нет. `/demotivate` обрабатывается на вашем клиенте и не уходит на сервер.

## Сборка из исходников

Нужна JDK 25.

```powershell
git clone https://github.com/ServChan/Demotivator.git
cd Demotivator
.\gradlew.bat build
```

На Linux и macOS используйте `./gradlew`. Готовый файл: `build/libs/demotivator-1.1.0.jar`.
